Foundation Plan

18 weeks · 3 phases · built around durability first

Phase 1 — Foundation current

Weeks 1–6

Structural strength, movement quality, ankle rehab, postural correction. Running returns gradually on physio's terms. Build the base everything else sits on.

Phase 2 — Build Weeks 7–12

Load the foundations. Proper strength progressions, increasing run volume, conditioning work introduced. Hyrox movements begin.

Phase 3 — Perform Weeks 13–18

Hybrid performance. Events become realistic targets. You're robust enough to train hard without breaking.

Guiding principles

Durability before performance. Every session has a purpose. Nothing is junk volume.

Strength and endurance coexist. 3 gym sessions per week, never competing with quality run days.

The ankle leads the way. Return to run is physio-gated. No shortcuts.

10 minutes mobility daily. Non-negotiable. This is maintenance work on a 46-year-old engine.

One full rest day. You lead a life. Sunday is protected.
